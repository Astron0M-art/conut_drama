怎么用

  1. 上传剧本（.docx / .txt / .md）。页面会自动找到「正文内容」，并按「第N集」「2-1、2-2…」分集；梗概、人物小传、大纲不会被翻译。
  2. 在左侧勾选要翻译的集（可全选）。点集号，右侧正文预览会定位到该集。
  3. 选择目标语言和模型：腾讯云（国内、速度快）或 VAPI（海外：Gemini / Claude / GPT）。
  4. 点批量翻译。单次最多 300 集，最多 20 集同时翻译，其余排队；单集失败不影响其它集，可点重试失败的集。
  5. 译文出来后可逐集预览，确认后导出整个剧本（DOCX）。

需要知道

  • 原稿里已有的括号外译（如 （西：…））送去翻译前会先去掉，避免重复翻译。
  • 导出有两种：覆盖原正文（只剩译文）或保留原文并附译文（中外对照）。都会生成新文件，不改你的原稿。
  • 可以只翻译一部分集再导出，没翻译的集保留中文原文；已完成的译文保存在本页，分批翻译、失败重试都不会丢。
  • 翻译中不要刷新或关闭本页，否则本页的进度和译文会丢失。想中途停下，点停止，已完成的集会保留。
  • 模型密钥由服务器保管，浏览器只提交模型名称。
