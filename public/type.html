使用说明

  1. 红色柱子 / 红色卡片是字数超出 550–1000 的集，点一下，右侧文档会自动定位到该集（居中显示）。
  2. 左侧窄条是缩略定位轴：红线是错误位置，点击或拖动可快速跳转。
  3. 在文档里鼠标框选文字，右侧会出现大号数字，实时显示选中部分的字数。
  4. 点任意一行可直接修改；顶部「一键自动修复」可补集标题、改集号。

什么不算字数

  • (La dosis es suficiente.) 括号里的外语翻译（灰色删除线标出）
  • △ 动作符号本身
  • 数字、空白
  • 「正文内容」之前的梗概、人物小传、大纲

勾选顶部「标出不计字数的翻译」，可在文档中看到每一处被排除的翻译。

标准格式：《剧名》→ 故事梗概 → 人物小传 → 分集大纲·粗纲 → 分集大纲·集纲 → 正文内容（第N集 / N-M 场次头 / 人物 / △动作 / 台词）

字数统计只在格式校验通过后进行。中文汉字、标点各计 1 字，夹杂英文每词计 1 字；括号外语翻译、△、数字、空白不计。
